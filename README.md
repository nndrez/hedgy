# Hedgy

Hedgy is a fast and simple Terminal User Interface (TUI) RSS feed reader written in Go. It allows you to manage and read your favorite RSS feeds directly from your terminal without distractions.

## Features

* TUI Interface: Clean and easy to use terminal interface.
* Feed Management: Add, organize, and refresh your RSS feeds.
* Article Reading: Read articles directly in the terminal, with HTML content converted to plain text.
* Zen Mode: Hide the sidebars to focus entirely on reading.
* Open in Browser: Quickly open the original article in your default web browser.
* Local Storage: All data is saved locally using SQLite.

## Usage and Controls

Hedgy is fully controlled via the keyboard. The application allows you to:
* Navigate easily between the feeds list, the articles list, and the main reading panel.
* Add new RSS feeds by entering their name and URL directly.
* Refresh a single feed or all feeds at once to fetch the latest articles.
* Toggle a fullscreen reading mode (Zen mode) for a distraction-free experience.
* Open the currently selected article in your system's default web browser.
* Quit the application safely at any time.
